# AGENTS.md

## Project
- Unity **6000.6.3f1**, URP 17.6.0, Linear, PC target, new Input System only (`activeInputHandler: 1`).
- Isometric 2.5D city-builder with an abstract (statistical) simulation. Design + roadmap: `Docs/GamePlan.md`.
- Game code lives under `Assets/_Game/` (never at `Assets/` root). Default scene: `Assets/_Game/Scenes/Main.unity`.

## Build / run / test
- **No CLI build, lint, or formatter** — the Unity Editor is the build system. Don't invent npm/dotnet build commands.
- Tests run via **Window > General > Test Runner** (`com.unity.test-framework` installed). EditMode unit tests (grid + simulation) live under `Assets/_Game/Tests/EditMode/`. Never `dotnet test`.
- `Library/`, `Temp/`, `Logs/`, `UserSettings/`, `obj/`, `Build/` are gitignored — never edit or commit.
- `*.csproj` and `City Game.slnx` are generated by Unity — don't hand-edit.

## C# / scripts
- No asmdefs **except** the grid core + simulation core and their tests: runtime code → `Assembly-CSharp`; anything under an `Editor/` folder → `Assembly-CSharp-Editor` (editor-only code must live there or player builds fail). Pure grid logic (`CellUtils`, `GridData`, `ZoneType`, `GridSystem`) lives in `Assets/_Game/Scripts/Grid/CityBuilder.Grid.asmdef`; pure simulation logic (`RoadNetwork` + the M6 sim systems and `BalanceConfig`) lives in `Assets/_Game/Scripts/Simulation/CityBuilder.Simulation.asmdef` (references `CityBuilder.Grid` by `GUID:`). EditMode tests live under `Assets/_Game/Tests/EditMode/` as `CityBuilder.Grid.Tests.asmdef` and `CityBuilder.Simulation.Tests.asmdef` (each references its runtime asmdef by `GUID:`); each test asmdef sits in its own folder (`.../EditMode/` and `.../EditMode/Simulation/`), since Unity allows only one asmdef per folder.
- Input System only — legacy `Input.*` throws at runtime. Game actions: `Assets/_Game/Input/CityBuilder.inputactions` (map `Gameplay`: Pan, Zoom, Pointer, Confirm, Cancel, Rotate, Demolish, RoadTool, SpeedDelta). `Assets/InputSystem_Actions.inputactions` is the project-wide template — unused by game code.
- URP: sprites/tilemaps need a URP sprite material (`Universal Render Pipeline/2D/Sprite-Unlit-Default`); built-in `Sprites/Default` renders pink.
- Obsolete APIs: `Object.GetInstanceID()` is a compile **error** (use `GetEntityId()`); `FindFirstObjectByType` is deprecated in Unity 6 — use `FindAnyObjectByType` instead.

## World / scene conventions
- Ground = `Grid` (`Rectangle` layout, `cellSize (1,1,1)`, rotated `-90° X` to lie flat in XZ) + `Ground` Tilemap (24×24 square tiles). The `Grid` GameObject sits at `(12,0,12)`; logical cells `(0..23)²` map to world `[0,24]²` (cell center `(x+0.5, 0, z+0.5)`). The Tilemap's raw cells are `-12..11` with a `Y↔Z` flip — `GridSystem` hides that via `LogicalToTileCell`/`TileCellToLogical`.
- Main camera is orthographic at 30° elevation / 45° azimuth; square cells read as 2:1 iso diamonds. Buildings stand along world **Y**.
- Because the camera is tilted, its XZ position is **not** the point it looks at on the ground — `ApplyBounds` clamps the *ground-look-at* point (ray `transform.forward` → `y=0`), not raw XZ. Camera sits at `(36.5, 20, 36.5)` so it frames plane center `(12, 12)`.
- Layers: `Ground`=8, `Buildings`=9, `Ghost`=10.
- **Not `IsometricZAsY`** — `Docs/GamePlan.md` §2/§5 is stale on this point.

## Systems (Milestone 0–6)

### Camera
- `Assets/_Game/Scripts/Camera/CameraSortAxis.cs` — applies `transparencySortMode` + `transparencySortAxis` in `Awake` (runtime-only, not serialized).
- `Assets/_Game/Scripts/Camera/IsoCameraController.cs` — pan (WASD/arrows; edge-scroll disabled via `m_EnableEdgePan`), mouse-position zoom (scroll wheel, 0.15 speed, 4–20 range), soft spring-back bounds (spring force 40, damping 0.88). Attached to Main Camera.

### Input
- `Assets/_Game/Scripts/Input/InputReader.cs` — wraps `CityBuilder.inputactions` (clones asset in `Awake`, enables `Gameplay` map). Exposes `Pan`, `Zoom`, `Pointer`, `ConfirmPressed`, `ConfirmHeld`, `CancelPressed`, `RotatePressed`, `DemolishPressed`, `RoadToolPressed`, `SpeedDelta`. Lives on a root `InputReader` GameObject in Main.unity.
- Bindings: `Confirm`=LMB, `Cancel`=RMB/Esc, `Rotate`=R, `Demolish`=Delete/Backspace, `RoadTool`=B, `SpeedDelta`=1–4 (keys 2/3/4 carry `Scale(factor=N)` processors so the action reads 1..4; without them every key reads 1).

### Grid
- `Assets/_Game/Scripts/Grid/CityBuilder.Grid.asmdef` — runtime asmdef for the grid core. Contains `GridSystem` (MonoBehaviour, references Unity Grid/Tilemap), `CellUtils`/`GridData`/`ZoneType` (pure C#).
- `Assets/_Game/Scripts/Grid/CellUtils.cs` — static math: `IsInBounds`, `Index`, `CellToWorld`/`WorldToCell` (origin-based), `Neighbors4`, `GetFootprint` (odd rotation swaps dims).
- `Assets/_Game/Scripts/Grid/GridData.cs` — pure C# state (`zones`, `roads`, `occupancy` int ids, `0` = empty): `GetZone/SetZone`, `IsRoad/SetRoad`, `GetBuildingLevel/SetBuildingLevel` (grown zone level `0..3`, `0` = undeveloped), `CountRoads`, `CanPlace` (rejects roads, occupied **and grown** cells), `Occupy`/`Release`, `GetFootprint`, `OnCellChanged`.
- `Assets/_Game/Scripts/Grid/ZoneType.cs` — `enum ZoneType { None, Residential, Commercial, Industrial }`.
- `Assets/_Game/Scripts/Grid/GridSystem.cs` — `MonoBehaviour` on the `Grid` GO; holds `Grid` + `Ground` Tilemap refs, `GridOrigin` = `(0,0,0)`, `GridSize` = `(24,24)`. Exposes `CellToWorld`/`WorldToCell` (logical `0..23`) and `LogicalToTileCell`/`TileCellToLogical`.
- Logical coordinate space is `(0..23)²`; cell `(x,y)` center → world `(x+0.5, 0, y+0.5)`.

### Placement
- `Assets/_Game/Scripts/Placement/PlacementController.cs` — mode machine `{ None, Road, Building, Demolish, Zone }`. Reads the shared `GridData` from `GameManager` in `Start` (**not** `Awake` — `GameManager.Awake` must run first). `RoadTool`/`Demolish` toggle modes, `Cancel` clears, `SelectBuilding(def)` + `R` rotates in `Building` mode, `Confirm` places/removes. Paints the `Roads` Tilemap via `GridSystem.LogicalToTileCell`; validation reuses `GridData.CanPlace` (no separate validator class). Holds a `Dictionary<int, BuildingInstance>` (occupant id → instance) to resolve building demolition. Roads cost `BalanceConfig.RoadCost`, buildings `def.Cost` (via `GameManager.Economy`; unaffordable = red ghost, no place). Placed/demolished buildings are reported to `GameManager.RegisterBuilding/UnregisterBuilding`. Demolish on a grown cell resets its level to 0 (zone stays, so it regrows). `SelectZone(ZoneType)` paints zones while LMB is **held** (drag); `ZoneType.None` = unzone; rezoning/unzoning resets the cell's grown level; roads/occupied cells can't be zoned; placing a road or building clears zoning under it. `PointerOverUI` (set by the toolbar each repaint) suppresses map clicks under UI. `DebugSeedCity()` lays a free cross-shaped road + R/C/I zones (debug shortcut).
- `Assets/_Game/Scripts/Placement/ZoneOverlay.cs` — on the `Grid/Zones` Tilemap (sibling of `Roads`, same material/sorting order 1); creates translucent runtime `Tile`s from the `ground_square` sprite per zone type and mirrors `GridData` zones via `OnCellChanged` (subscribes in `Start`).
- `Assets/_Game/Scripts/Placement/GhostRenderer.cs` — `SpriteRenderer` on `Ghost` layer 10, green/red tint; `Show(worldPos, size, valid)` scales it to a footprint. Must be rotated `-90° X` to match the `Grid`, else it renders standing up.
- `Roads` Tilemap (child of `Grid`, layer 9, URP sprite material, sorting order 1) + `Art/road_tile.asset` (gray `Tile` reusing the `ground_square` sprite).

### Roads (M5)
- `Assets/_Game/Scripts/Simulation/CityBuilder.Simulation.asmdef` — runtime asmdef for pure simulation logic; references `CityBuilder.Grid`.
- `Assets/_Game/Scripts/Simulation/RoadNetwork.cs` — pure C# connectivity view over the shared `GridData` roads. Constructed with `GridData`; subscribes `OnCellChanged` to mark the connectivity cache dirty. `HasRoadAccess(cell)` = a 4-neighbor is a road connected (4-connected BFS) to the map edge (the "entry"); `IsConnectedToEntry(roadCell)`. Multi-source BFS from edge road cells recomputes lazily; diagonal adjacency does **not** count.

### Simulation (M6)
- All pure, in `CityBuilder.Simulation.asmdef`: `GameSpeed` enum, `DemandSnapshot` struct, `CityModifiers` (housing/jobs/upkeep/service count from player-placed buildings — supplied by the runtime because `BuildingDefinition` is in `Assembly-CSharp`), `BalanceConfig` (ScriptableObject, all §7 tunables; asset `Scriptables/Balance/BalanceConfig.asset`), `EconomySystem`, `PopulationSystem`, `DemandSystem`, `GrowthSystem`, `SimulationSystem`.
- `SimulationSystem.Tick()` order: recount capacity → **Demand → Growth → Population → Economy**. Grown buildings are **not GameObjects in the sim**: `GrowthSystem` raises `GridData` building levels (row-major scan, new cells before upgrades, eligible = zoned + road access + not road/occupied); capacity per level = `BalanceConfig.CapacityForLevel` (4/8/16).
- **Balance deviates from `GamePlan.md` §7** (the doc's formulas deadlock at ~1–4 pop): constant residential base demand 0.40 (doc: 0.30 only at pop 0), move-in = `ceil(Vacant * 0.20)` not scaled by demand, C/I demand denominator floor 5 (doc: 20), `Employed = min(Workers, Jobs)` (doc: `min(Population, Jobs)`). Seeded city → ~212 pop, +$234/day at day 60. Tuned fields are tagged "(tuned)" in `BalanceConfig`.
- Tests: `Tests/EditMode/Simulation/SimulationTests.cs` (create `BalanceConfig` via `ScriptableObject.CreateInstance`).

### Core / Buildings (M4, M6)
- `Assets/_Game/Scripts/Core/GameManager.cs` — owns the **single shared `GridData`** (created in `Awake` from `GridSystem.GridSize`), the `RoadNetwork` (`Roads`), the `BuildingDatabase`, `BalanceConfig` (`Balance`; falls back to defaults with a warning if unassigned) and the `SimulationSystem` (`Simulation`, plus `Economy`/`Population`/`Demand` shortcuts). Subscribes `TimeManager.OnTick` → `Simulation.Tick()` → raises `GameEvents`. Tracks `CityModifiers` from registered buildings. `TimeManager` is exposed as `Clock` (not `Time`, to avoid shadowing `UnityEngine.Time`). Root `GameManager` GameObject in Main.unity also carries `TimeManager` and `GrowthVisuals`.
- `Assets/_Game/Scripts/Core/TimeManager.cs` — accumulates `deltaTime × speed`, fires `OnTick` once per in-game day (max 4 ticks/frame), advances Day/Month/Year. Keys 1–4 = Paused/1×/2×/4×; `SetSpeed`, `TogglePause`.
- `Assets/_Game/Scripts/Core/GameEvents.cs` — static bus (`MoneyChanged`, `PopulationChanged`, `DateChanged`, `DemandChanged`, `SpeedChanged`, `BuildingPlaced/Removed`, `CellChanged`); subscribers are cleared on `SubsystemRegistration` so disabled domain reload doesn't leak handlers. M7 UI should bind here.
- `Assets/_Game/Scripts/Buildings/GrowthVisuals.cs` — listens to `GridData.OnCellChanged`; spawns/rescales/destroys a primitive cube per grown cell (height = level × 0.6, layer 9, `BuildingHouse.mat` tinted per zone via `MaterialPropertyBlock` `_BaseColor`).
- `Assets/_Game/Scripts/Buildings/BuildingCategory.cs` — `enum { Zone, Road, Service, Utility, Decoration }`.
- `Assets/_Game/Scripts/Buildings/BuildingDefinition.cs` — `ScriptableObject` (Id, DisplayName, Category, Icon, Prefab, Size, Cost, UpkeepPerDay, HousingCapacity, JobsProvided, HappinessEffect, ZoneRestriction, UnlockPopulation, **Height**). `Height` is an addition beyond `GamePlan.md` §6 (drives the 3D cube visual).
- `Assets/_Game/Scripts/Buildings/BuildingDatabase.cs` — `ScriptableObject` list + `GetById`.
- `Assets/_Game/Scripts/Buildings/BuildingInstance.cs` — `MonoBehaviour` on the building prefab. Mints a **static sequential `int`** occupant id (starts at 1; `0` = empty in `GridData`) — do not use `GetInstanceID()`. `Init(grid, def, origin, rotation)` calls `GridData.Occupy` then sets the transform (position = footprint center at `y = height/2`, scale = footprint × height, Y-rotation = `rotation*90°`); `Demolish()` calls `Release`.
- Placeholder building art is **3D cube primitives** (not sprites) tinted with a `Universal Render Pipeline/Unlit` material (`Art/BuildingHouse.mat`). Prefab `Prefabs/Buildings/House.prefab` (layer 9); def `Scriptables/Buildings/House.asset`; db `Scriptables/Buildings/BuildingDatabase.asset`. `Park` (`park`): Service, 2×2, $500, $5/day upkeep, height 0.25, `Art/BuildingPark.mat`, `Prefabs/Buildings/Park.prefab` — each Service building adds +0.05 happiness (cap +0.20) via `CityModifiers.ServiceCount`. `House` stays in the database but has no toolbar button (R/C/I grow from zones, not manual placement).

## Unity 6 gotchas
- `Camera.transparencySortMode`/`transparencySortAxis` are **runtime-only** — must be set in code, not the Inspector.
- Editing a Tilemap from editor script: `MarkSceneDirty` + `EditorUtility.SetDirty(tilemap)` before `SaveScene`, else tiles don't persist.
- `AssetDatabase.CreateAsset` can't create `.inputactions` — write `InputActionAsset.ToJson()` to path, then `ImportAsset`.

## Unity MCP (`opencode.json` registers the `unity` server)
- `RunCommand` scripts must be `internal class CommandScript : IRunCommand` with `Execute(ExecutionResult result)`; `System.Reflection` is blocked.
- Adding a new `.cs` triggers a domain reload → the bridge may briefly report "Unity not detected"; retry.
- Asset deletion via MCP pops an editor modal — delete assets in the Editor UI instead.
- Ask the user to confirm the **first** asset generation of a conversation — it blocks until every generation finishes.

## VCS
- Commit every asset's **`.meta`**; never delete or ignore them.
