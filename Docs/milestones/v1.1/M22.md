# M22 — Road layout (outline, 2026-10-05)

*Outline only: expanded into a full plan (goal, done-when, design decisions, lettered steps, risks) when the
milestone starts (`milestone-workflow`). Part of the 1.1 roadmap: [`Roadmap.md`](Roadmap.md) (order and shared
decisions). Where it fits: `../../GamePlan.md` §12; systems as built: §13.*

**Save:** v8.

- **2-wide avenues.** The Avenue tool previews and lays a 2-cell strip (the second lane on the drag's right-hand
  side, flipped with R), refuses where the pair doesn't fit, upgrades a street to an avenue only when the
  neighbouring lane can be added. Art: `RoadTilemapView` draws the median between paired avenue cells. Capacity per
  cell re-tuned so a 2-wide avenue carries about what a 1-wide one did plus the width bonus. Demolishing one lane
  demolishes the pair.
- **One-way highways.** `GridData` gains a per-road direction byte (0 = two-way; N / E / S / W), saved in v8
  (migration: existing highways become two-way so old cities keep working, with a toast offering nothing).
  `TrafficSystem` / `RoadNetwork` build a directed graph for highway cells; placement sets direction from the drag;
  arrows on highway tiles; vehicles follow direction; a "Reverse direction" action in `SelectionPanel`. Ramps =
  any highway cell meeting a street (no interchanges in 1.1).
- Watch `PerfBenchmark` (directed Dial's algorithm on 96²).
