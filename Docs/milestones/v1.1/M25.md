# M25 — Custom assets (plan, 2026-10-06)

*Part of the 1.1 roadmap: [`Roadmap.md`](Roadmap.md) (order and shared decisions). Where it fits:
`../../GamePlan.md` §12; systems as built: §13 (Core / Buildings, UI, Save / load).*

**Save:** none (buildings are saved by `Id`; a save that names a missing custom building is handled in 25b).

## Goal
Two feedback items. (1) **Guidance** on adding your own assets: a written guide and an Editor wizard, so a modder
who owns the Unity project can add a building without reading the code. (2) A **searchable placement menu**: one
panel that lists every building you can place, with a search box and filters, where custom items are tagged
"Custom". No sim number, save format or balance changes. Scope is fixed by the roadmap decision (2026-10-05):
**in-Editor pipeline only, no loading of models from disk in the shipped player.**

## Done when
- `Docs/CustomAssets.md` explains, with a worked example that is also a test fixture: the art contract, the two
  kinds of custom asset (placeable building, growable variant), import settings, the wizard, testing in Play mode.
- *CityBuilder › Add Custom Building…* creates a valid `BuildingDefinition`, adds it to the `BuildingDatabase` and
  (for growables) the chosen `AgeVisualSet` slot, validates against `ArtContract` first and refuses with a readable
  list of problems. Re-running it on the same `Id` updates instead of duplicating.
- The placement menu (hotkey **F**, rebindable, plus a toolbar button) lists all buildings the city can build now,
  with a search box (name, id, group, effect words), group and age filters, a **Custom** tag and a "Locked" section
  showing what a tech would unlock. Picking an item starts placement, as the group flyouts do. It works with
  keyboard only (type to search, arrows, Enter, Esc).
- A custom placeable shows up in the toolbar group flyouts as before **and** in the menu; a custom building with an
  unknown `RequiredTech` or a missing prefab is skipped with one warning, never an error in the player.
- A custom residential / commercial / industrial placeable works end to end: it adds housing or jobs (the existing
  `CityModifiers` path), costs upkeep, is selectable and saves / loads.
- All EditMode tests green with **unchanged numbers**; new tests (below); a UI-only virtual-input play-through of
  the menu passes; docs updated.

## Design decisions (defaults the user can change)
| Topic | Default | Why / alternative |
|---|---|---|
| Landmarks (growable placed as a ploppable) | **Dropped from 1.1.** A custom "residential building you place yourself" is a placeable `BuildingDefinition` with `HousingCapacity` (and `JobsProvided` for shops / factories); `GameManager` already folds both into `CityModifiers`. | The outline's "landmark counts as that zone's capacity" would need a new per-cell path in `CapacityModel` and `GridData` and a save version. The placeable route gives the same player-visible result with no sim change. Alternative: add it as a 1.2 item. |
| Menu scope | **Placeable buildings only** (`Service`, `Utility`, `Decoration`). Roads, zones, pipes keep their toolbar buttons. | Those are tools, not items; searching "road" is still answered by a hint row that selects the tool (cheap, 25c). |
| Hotkey | **F** (Find), new `Gameplay` action `BuildMenu`, in the Controls rebind list. | B is the Road tool (found in 25c; the first draft said B), Q/E/R/V/P are taken; F is free. |
| Locked items | Shown greyed in a separate section with the tech name, not placeable. | Tells a player why a search for "hospital" finds nothing placeable yet. |
| Custom tag | `BuildingDefinition.IsCustom` (serialized bool the wizard sets), not an `Id` prefix. | An id convention can't be enforced; a flag is explicit and the shipped content stays untagged. |
| Wizard output folder | `Assets/_Game/Scriptables/Buildings/Custom/` and `Assets/_Game/Prefabs/Custom/`. | Keeps modder content separate from generated content (`Tools/gen_age_content.py` never touches `Custom/`). |
| Missing custom building in a save | The loader skips the placed building with a toast ("Custom building X is missing"), the cell becomes empty land; the save file is left as is. | Never crash on a removed mod. Needs a look at how `SaveSystem` / `GameManager` resolve ids (25b). |
| Icon | Wizard takes an optional sprite; otherwise renders the prefab to a small icon with `AssetPreview` and saves it. | A generic placeholder is always acceptable. |

## Architecture
- **Runtime (`Assembly-CSharp`):** `BuildingDefinition.IsCustom`; `BuildMenu` panel (`Scripts/UI/`, created at runtime
  by code like `BudgetPanel`, so no scene or prefab diff; shares the `SidePanels` slot); a small pure `BuildMenuFilter`
  (static: query + group + age + custom filter over a list of entries, ranking name-prefix above substring above
  effect words) so the search is unit-testable; `InputReader` / `KeyBindings` get `BuildMenu`; `EscapeRouter` entry.
- **Editor (`Assembly-CSharp-Editor`):** `CustomBuildingWizard` (EditorWindow) + `CustomBuildingValidator` (wraps
  `ArtContract.Validate`, adds definition checks: unique Id, tech exists, cost ≥ 0, size ≥ 1×1, prefab present).
  `ArtContract.Validate` stays for growable slots; placeables use `ArtContract.ValidatePlaceable` (unit box + `BuildingInstance`, see 25a).
- **Content:** nothing generated. One sample custom building ships under `Custom/` as the worked example (a
  "Market Hall" placeable, Renaissance, a few unit-box masses like the shipped placeables) so the doc and tests have a real subject.
  It must not change any baseline: hung off an existing tech, `AgeBalanceTests` / `EngagedCity` don't build it.
- **No change** to `CityBuilder.Simulation`, `CityBuilder.Grid` or `SaveData`.

## Risks / open questions
- **Toolbar flyouts and the menu overlap.** Both list the same buildings; the menu must reuse the flyouts' pick path
  (`ToggleBuilding`) so cost colouring, the ghost and the tutorial highlight keep one source of truth.
- **Search on WebGL / keyboard focus.** A focused `TMP_InputField` swallows hotkeys (B, Q, E, V); check that typing
  "bank" doesn't rotate the camera, and that Esc leaves the field first (`EscapeRouter` priority).
- **Wizard writes assets from an EditorWindow.** Follow `scene-prefab-editing` (hand-written `.meta` not needed:
  use `AssetDatabase`, then commit Unity's metas); never leave `Main.unity` dirty.
- **Prefab contract surprises.** Modders' models rarely have pivot-at-ground-centre; the validator reports numbers
  and the guide shows the fix (a parent root), rather than the wizard silently re-parenting.
- **Perf.** The menu is UI only and closed by default; no per-frame cost when hidden. No `PerfBenchmark` re-run needed.
