# M27 — Drag tools (plan, 2026-10-16)

*Part of the 1.2 roadmap: [`Roadmap.md`](Roadmap.md). Where it fits: `../../GamePlan.md` §12; systems as built: §13
(Placement, Roads).*

## Goal
Road-type tools (street tiers, Avenue, Highway) and the Pipe tool lay a **straight line**: press on a cell, drag, the line follows the
cursor along x or z only, and nothing is built until the button is released. The Demolish tool removes everything the
cursor passes over while the button is held.

## Done when
- Road / Avenue / Highway: press–drag–release builds exactly the previewed straight run; the preview shows the cells,
  the total cost and whether it is affordable; Cancel (right click / Esc) during a drag builds nothing; a single click
  still lays one cell (an Avenue pair along the last heading, as today).
- Pipes: the same press–drag–release straight line; a run that starts on a pipe removes the pipes along it (today's
  erase rule, applied to the run).
- Highway runs are one-way along the drag direction (unless R = two-way); Avenue pairs follow the drag's heading and the
  R side flip; upgrades over existing roads cost the difference, as today.
- Demolish: holding the button and moving removes roads, grown blocks and rubble under the cursor, each cell once per
  drag; placed buildings are collected and, when *Confirm demolish* is on, asked about once on release.
- EditMode green; `RoadLayoutDriver`, `FinishDriver`, `TutorialDriver`, `CameraToolbarDriver`, `DensityDriver`,
  `Release11Driver` updated for straight drags and passing, plus a new `DragToolsDriver` (UI-only); docs updated.

## Current behaviour (as read 2026-10-16)
`PlacementController.HandleConfirm` paints Zone / Pipe / Road while `ConfirmHeld`: every frame the cell under the cursor
is laid at once (`TryPlaceRoad` → `TryPlaceAvenue` / `FollowHighwayDrag`, heading = step between the last two painted
cells via `RoadLayout.HeadingOf`). So a road drag is freehand (it can wander and leave diagonal staircases) and is paid
cell by cell. Demolish uses `ConfirmPressed`, one cell per click (`DemolishAt`). The ghost (`GhostRenderer.Show(centre,
size, valid)`) draws one rectangle — enough for a straight run, which is a rectangle.

## Design decisions (answered 2026-10-16: pipes use the line too; demolish removes everything under the cursor)
| Topic | Default | Why / alternative |
|---|---|---|
| Axis of the line | Locked by the larger of \|dx\|, \|dz\| from the start cell, re-evaluated every frame (the line can swing from x to z while held) | Alternative: lock on the first cell moved and keep it for the drag. Re-evaluating feels like other city builders and costs nothing. |
| Build timing | Nothing is laid until release; the cells are then laid in order from the start cell, through the existing per-cell code (so Avenue pairing, highway direction and upgrade pricing stay one implementation) | Building while dragging (today) cannot be cancelled. |
| Not enough money | Preview turns red and the hint says the shortfall; on release the run is laid in order until money runs out, with one warning (today's behaviour) | Alternative: refuse the whole run. Partial is kinder and matches the current per-drag warning. |
| Blocked cells in the run | Skipped (buildings, out of bounds, a lane the Avenue can't pair); the hint counts them | Alternative: stop the line at the first obstacle. |
| Pipes | **Same straight line as roads** (asked); a run that starts on a pipe erases pipes along it; preview shows the pipe count and cost | Freehand paint (today), not taken. |
| Demolish drag | **Everything under the cursor** (asked). Paint: every cell the cursor enters, freehand, removes whatever is there (road / grown block / rubble); placed buildings deduped by occupant id and confirmed once on release ("Demolish 3 buildings?") | Only removing the kind the drag started on — not taken. |
| Demolish sound | One demolish sound per cell, throttled to ~10 per second | Avoid a wall of noise on a long drag. |

## Architecture
- Pure helper in the Grid asmdef: `RoadLayout.StraightRun(Vector2Int start, Vector2Int cursor) -> (heading, length)`
  and an enumerator of the cells, with EditMode tests (axis choice, ties, zero length, negative directions, bounds).
- `PlacementController`: road and pipe modes switch from paint to press / hold / release (Zone stays paint). New state `m_LineStart`,
  `m_LineEnd`; `HandleConfirm` records the start on `ConfirmPressed`, updates the end while held and on release calls
  `CommitRoadLine()`, which resets `m_DragLast` and feeds each cell of the run to the existing `TryPlaceRoad` (or `TryPipe`, with `m_PipeErasing` from the start cell) (so
  `FollowHighwayDrag` / `TryPlaceAvenue` get the heading from consecutive cells exactly as now). `FlushPendingLane`
  still covers the single-click Avenue case. Cancel during a line clears it (`EscapeRouter` / `InputReader.Cancel`
  are checked before the tool cancel, so the first Esc cancels the line, the second the tool).
- Preview: `UpdateGhost` shows one rectangle over the run (two cells wide for an Avenue: the pair side offset), valid
  when every cell can be laid and the total is affordable; `UpdateHint` gives "Avenue ×12  $1,800" / "$450 short" /
  "3 cells blocked". Cost = Σ `LaneCost` / `PairCost` / `tiers.Cost` over the run — a dry run of the same rules
  (factor out `RoadCellCost(cell, tier)` used by both preview and commit).
- Demolish: `Mode.Demolish` joins the held tools; a per-drag `HashSet<Vector2Int>` of visited cells and a
  `HashSet<int>` of pending occupant ids; `DemolishAt` gains a `deferConfirm` path that adds placed buildings to the
  pending set; `FlushPendingDemolish()` on release asks once (mirrors `FlushPendingRepaint`) or removes at once when the
  setting is off. Grown blocks still go without asking (as today).

## Risks / open questions
- The tutorial and the Controls panel describe dragging roads; check the wording still fits ("drag a straight line").
- An Avenue run that turns (x then z) needs two drags now; the junction code (`RoadLayout.MakeJunction`) already
  handles a second run crossing or meeting the first — covered in the 27b Play-mode check.
- Drags that start over UI are ignored today (`IsPointerOverUI`); a run that is *released* over UI must still commit.
